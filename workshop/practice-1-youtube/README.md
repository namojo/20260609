# 실습 1 · 유튜브 콘텐츠 기획 팀

교재: https://namojo.github.io/harness-edu2/practice/1-youtube.html

**학습 목표:** 업무 설명 한 문장으로 전문가 팀을 만들 수 있다.

## 준비물

입력 파일이 없습니다. Claude Code가 실행되고 하네스 플러그인이 설치되어 있으면 됩니다.
이 폴더에서 `claude` 를 켜고 아래 브리프를 붙여넣으세요.

## 브리프 (그대로 복사하세요)

```
하네스를 구성해줘.
[브랜드/주제]를 위한 유튜브 콘텐츠 기획 팀이 필요해.
트렌드 조사, 8–10분 대본 기획, 제목·태그 SEO, 썸네일 콘셉트를 맡기고,
최종적으로 1주치 콘텐츠 기획안을 만들어줘.
대상은 [20대 직장인]이고, 주장마다 근거 출처를 남겨줘.
```

`[브랜드/주제]` 와 `[20대 직장인]` 을 본인 것으로 바꾸세요.

## 브리프의 네 요소

| 요소 | 이 브리프에서 | 내 업무로 바꿀 때 |
|---|---|---|
| 목표 | 1주치 콘텐츠 기획안 | 무엇을 받고 싶은가 |
| 대상 | 20대 직장인 | 누구를 위한 것인가 |
| 역할 | 트렌드 조사 · 대본 기획 · 제목·태그 SEO · 썸네일 콘셉트 | 누가 필요한가 |
| 기준 | 주장마다 근거 출처 | 무엇을 지켜야 하는가 |
