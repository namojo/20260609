# 실습 2 · 브랜드 마케팅 전략보고서

교재: https://namojo.github.io/harness-edu2/practice/2-marketing.html

**학습 목표:** 독립 조사 → 통합 → 별도 검토를 프롬프트 한 편에 담을 수 있다.

## 준비물

입력 파일이 없습니다. 다만 **이 실습의 결과물을 실습 3에서 다시 씁니다** — 결과를 이 폴더에 파일로 저장하세요 (예: `strategy.md`).

## 브리프 (그대로 복사하세요)

```
[브랜드]의 [제품/서비스]를 위한  마케팅 전략보고서 하네스를 구성해줘.
시장·고객·경쟁·채널을 독립적으로 조사한 뒤 전략가가 통합하고,
별도 리뷰어가 근거·실행 가능성·누락을 점검하게 해줘.
최종 산출물은 1페이지 요약, 실행 우선순위 표, 측정지표를 포함해줘.
사실과 가정을 구분하고 모든 외부 주장에 출처를 남겨줘.
```

## 이 브리프에 들어 있는 패턴 두 개

| 브리프의 문장 | 패턴 |
|---|---|
| `시장·고객·경쟁·채널을 독립적으로 조사한 뒤 전략가가 통합` | **팬아웃 / 팬인** |
| `별도 리뷰어가 근거·실행 가능성·누락을 점검` | **생성-검증** |

```
        ┌─ 시장 조사 ─┐
브리프 ─┼─ 고객 조사 ─┼─→ 전략가(통합) ─→ 리뷰어(검증) ─→ 최종
        ├─ 경쟁 조사 ─┤
        └─ 채널 조사 ─┘
```

조사자 4명은 **서로를 기다리지 않습니다.** 그것이 팬아웃/팬인의 실물입니다.
