# 실습 3 · 샘플 형식으로 새 PPT 만들기

교재: https://namojo.github.io/harness-edu2/practice/3-pptx.html

**학습 목표:** 앞 실습의 산출물을 다음 입력으로 재사용하고, 내용과 형식을 나눠 검토할 수 있다.

## 준비물

| 필요한 것 | 어디에 |
|---|---|
| `sample.pptx` — 형식·디자인 참조 원본 (5장, 약 1MB) | 이 폴더 |
| 전략보고서 — 슬라이드에 담을 내용 | 실습 2의 결과물 |
| 실습 2를 건너뛴 경우 | `example-strategy.md` (이 폴더) |

> **`sample.pptx`는 렌더된 이미지 슬라이드입니다.** 텍스트를 복사할 수 없습니다.
> 그것이 이 실습의 의도입니다 — 붙여넣는 것이 아니라 **눈으로 읽어 규칙을 언어로 정리**하는 것이 첫 단계입니다.

## 브리프 (그대로 복사하세요)

```
sample.pptx의 형식과 디자인을 재해석해 전략 보고서를 PPT로 만드는 하네스를 구성해줘.
먼저 sample.pptx에서 형식 규칙 — 폰트 계층, 외곽 여백, 정렬선, 색의 역할, 카드·표현 방식, 한 장의 정보량 — 을 추출하게 해줘.
그 규칙과 실습 2에서 만든 마케팅 전략보고서를 이용해 새 슬라이드 3장을 만들어줘.
1장은 문제와 기회, 2장은 실행 우선순위, 3장은 측정과 다음 행동으로 구성해줘.
내용 리뷰와 형식 리뷰를 맡는 리뷰어를 각각 두고, 텍스트·표·도형은 편집 가능하게 유지해줘.
```

## 추출할 형식 규칙 6종

"예쁘게 따라 해" 대신 **뽑을 항목을 지정하는 것**이 이 실습의 핵심입니다.

1. **폰트 계층** — 제목 / 소제목 / 본문 / 캡션의 크기·굵기 관계
2. **외곽 여백** — 슬라이드 가장자리 안전 영역
3. **정렬선** — 좌측 기준선, 열 구조
4. **색의 역할** — 지배색 / 강조색 / 상태색의 쓰임 구분
5. **카드·표현 방식** — 정보를 담는 반복 단위
6. **한 장의 정보량** — 한 슬라이드가 다루는 메시지 개수

## 만들 3장

`문제 → 선택 → 측정`

| 장 | 제목 | 답해야 하는 질문 |
|---|---|---|
| 1 | 문제와 기회 | 왜 지금 이 타깃과 메시지인가? |
| 2 | 실행 우선순위 | 무엇을 먼저, 누가, 언제 할 것인가? |
| 3 | 측정과 다음 행동 | 무엇으로 성공을 판단할 것인가? |


## sample.pptx 출처

**가상 브랜드 '핀치(PINCH)'의 반려견 덴탈 츄 '데일리츄' 제안서**입니다. 5장 · 16:9.
브랜드·수치·주장은 모두 가공된 것이며, 이미지 생성 도구로 만든 교육용 자료입니다.

실습 2의 예시 전략보고서(오르빗 그래놀라)와 **일부러 다른 카테고리**로 만들었습니다 — 이 샘플에서 가져올 것은 **형식뿐**이고 내용은 실습 2에서 온다는 것이 분명해지도록.
