# 매체 성과 표준용어집 — 루미에르 캠페인

> 정하늘 대리(한빛애드 마케팅솔루션팀)가 주간 성과 리포트를 만들 때 쓰는 지시서입니다.
> **2차시 사례의 결과물**이고, 5차시 출력 계약·6차시 Tool의 재료가 됩니다.

## 언제 쓰는가

매주 월요일, 5개 매체에서 내려받은 성과 파일(`data/` 폴더)을 합쳐 광고주 제출용
주간 리포트를 만들 때. 매체가 추가되면 아래 **용어 매핑** 표에 행만 더한다.

---

## 1. 용어 매핑

| 표준 항목 | 매체별 표기 |
|---|---|
| **노출** | 노출수(네이버) · 노출(카카오) · Impressions(메타) · Impr.(구글) · Imp(틱톡) |
| **클릭** | 클릭수(네이버) · 클릭(카카오) · Clicks(메타·구글) · Clk(틱톡) |
| **집행액** | 광고비(VAT별도)(네이버) · 소진금액(VAT포함)(카카오) · Amount spent (KRW)(메타) · Cost(구글) · Spend(틱톡) |
| **전환** | 전환수(네이버) · 전환(카카오) · Results(메타, **목적이 Purchases 일 때만**) · Conversions(구글) · CV(틱톡) |
| **전환매출** | 전환매출(네이버) · 매출(카카오) · Purchase conversion value(메타) · Conv. value(구글) · CV Value(틱톡) |
| **캠페인** | 캠페인(네이버) · 캠페인명(카카오) · Campaign(메타·구글) · campaign_name(틱톡) |
| **일자** | 일자(네이버) · 날짜(카카오) · Date(메타) · Day(구글) · stat_date(틱톡) |

### 주의가 필요한 항목

**메타의 `Results` 컬럼** — 캠페인 목적(`Objective`)에 따라 의미가 바뀐다.

| Objective | Results 의 뜻 | 처리 |
|---|---|---|
| `Purchases` | 구매 전환수 | **전환으로 인정** |
| `Link clicks` | 링크 클릭수 | **전환 아님.** 전환 0 으로 두고 비고에 `[목적: 트래픽]` 표시 |

목적을 확인하지 않고 `Results` 를 그대로 전환으로 합산하면 전환수가 부풀려진다.
이 데이터의 `LUMIERE_Serum_Traffic` 은 14일치 전부 목적이 `Link clicks` 이므로 전환은 0 이다. Results 에는 일 2,000여 건의 클릭수가 들어 있어, 그대로 합산하면 메타 전환이 14배로 부풀려진다.

## 2. 형식 규칙

| 항목 | 규칙 | 원본 예시 |
|---|---|---|
| 일자 | `YYYY-MM-DD` | `26.7.13`(카카오) · `2026/07/13`(구글) · `20260713`(틱톡) 모두 변환 |
| 집행액 | **VAT 별도** 원 단위 정수, 천 단위 콤마 | 카카오는 VAT 포함이므로 **÷ 1.1** 후 반올림 |
| 비율 | 소수점 둘째 자리 + `%` | `1.15%` |
| 매체명 | `네이버GFA / 카카오모먼트 / 메타 / 구글애즈 / 틱톡` **다섯 가지만** | `Meta`, `페이스북` 등으로 쓰지 않음 |
| 증감 | `+12.3%` 또는 `-8.1%p` | 전주 대비 |

### 재계산 규칙 (매체 리포트 값을 그대로 쓰지 않음)

| 지표 | 계산식 |
|---|---|
| CTR | 클릭 ÷ 노출 |
| CPA | **VAT 별도 집행액** ÷ 전환 |
| ROAS | 전환매출 ÷ **VAT 별도 집행액** × 100 |
| 목표 달성률 | ROAS ÷ 350% × 100 <span>(캠페인 목표: 월 ROAS 350%)</span> |

---

## 3. 금지 사항

1. **원본 수치를 변경하지 않는다.** 반올림이 필요하면 원본을 보존하고 별도 컬럼에 표기한다.
2. **매체 리포트의 CTR·CPA·ROAS 를 그대로 옮기지 않는다.** VAT 기준과 전환 정의가 매체마다 달라 비교가 성립하지 않는다. 반드시 위 식으로 재계산한다.
3. **노출 1,000 미만**인 캠페인은 CTR·CVR 을 계산하지 않고 `데이터 부족` 으로 표시한다.
   (이 데이터의 `Lumiere_Spark_Test` 가 해당된다 — 노출 600대)
4. **용어집에 없는 컬럼은 추측하지 않는다.** `[미확인: 컬럼명]` 으로 별도 보고한다.
5. 전환이 0 인 항목의 CPA 는 `-` 로 둔다. 0 으로 나누지 않는다.

---

## 4. 이 용어집이 잡아내는 것 (검수 포인트)

이 지시서 없이 5개 파일을 통합하면 아래가 조용히 틀린다.

| 함정 | 없으면 생기는 일 (이 데이터 실측) |
|---|---|
| 카카오 VAT 포함 | 카카오 ROAS **163.3% → 148.5%** — 성과가 실제보다 나쁘게 보고된다 |
| 메타 `Results` | 트래픽 캠페인 클릭이 전환으로 합산되어 메타 전환 **1,120 → 15,683건(14배)**, CPA **34,886 → 2,491원** |
| 날짜 3형식 | 주차 집계가 어긋난다 |
| 노출 600대 테스트 캠페인 | 전환 0인데 CTR 1.6% 로 효율이 좋아 보인다 |

**정답**: 용어집을 적용하면 W3 전체 전환 **5,705건** · CPA **24,136원** · ROAS **366.9%**
(목표 350% 대비 104.8%), 전주 대비 CPA **+13.1%** 입니다.
