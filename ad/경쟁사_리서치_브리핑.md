# 경쟁 브랜드 캠페인 리서치 — 실습 브리핑

> 교육 사이트 **3차시(일의 단계 판단)** 사례의 실제 입력 자료입니다.
> 1차시 업무 지도의 **5번 업무**("신규 제안 시 — 경쟁 브랜드 캠페인 리서치")를
> 여기서 직접 돌려 봅니다.
> 등장하는 회사·브랜드는 모두 **가상**이며, 조사 결과는 그때그때 웹 검색 시점에 따라 달라집니다.

## 1. 상황

한빛애드가 **신규 스킨케어 브랜드 '아뜰리에 담'** 광고주 피칭을 준비 중입니다.
제안서 마감은 **이번 주 금요일**. 정하늘 대리가 맡은 부분은 제안서 3페이지 —
&quot;경쟁 환경 및 디지털 마케팅 트렌드&quot; 섹션입니다.

담당 임원의 요청은 이렇습니다.

> &quot;스킨케어 업계에서 요즘 AI를 광고에 어떻게 쓰는지, 실제 사례 3개만 찾아서
> 한 페이지로 정리해 줘. 우리 제안에 넣을 인사이트도 같이.&quot;

1차시에서 이 업무는 **4시간 · 비정기 · ⓐ AI 보조**로 분류되었습니다. 이번 실습에서
그 판정이 맞는지 **직접 돌려서 확인**합니다.

## 2. 조사 범위

| 항목 | 내용 |
|---|---|
| 업종 | 스킨케어 · 색조 화장품 (국내외 무관) |
| 알아야 할 것 | ① AI 기반 개인화 추천·타겟팅 광고 사례, ② 숏폼·AI 생성 크리에이티브 활용 사례, ③ 리테일 미디어(자사몰·플랫폼 내 광고) 트렌드 |
| 산출물 | 사례 **3건** + 출처·날짜 + &quot;우리 제안에 왜 유효한지&quot; 한 줄씩 |
| 분량 | 1페이지 (A4 기준) |
| 마감 | 실습에서는 &quot;지금 당장&quot;으로 가정 |

## 3. 안전한 입력 범위 — 신호등

1차시에서 배운 신호등을 이 업무에도 그대로 적용합니다.

| 신호 | 이 업무에서 다루는 자료 |
|---|---|
| 🟢 넣어도 됨 | 경쟁 브랜드의 **공개된** 광고 사례, 보도자료, 업계 리포트, 공개 수치 |
| 🟡 조건부 | '아뜰리에 담'의 제품 콘셉트 — 실습 중에는 구체적 성분·가격 대신 &quot;스킨케어 신규 브랜드&quot;로만 언급 |
| 🔴 넣지 않음 | 피칭 경쟁 PT사(다른 대행사)의 제안 내용, 광고주 내부 예산 추정치 |

## 4. 실습 방법 — Level 1로 먼저 해보기

### 준비 — 이 폴더에서 Claude Code 실행

```powershell
cd C:\harness-edu\ad     # macOS: cd ~/harness-edu/ad
claude
```

### 입력창에 붙여넣기

```
너는 한빛애드의 AE 정하늘 대리야.
이 폴더의 경쟁사_리서치_브리핑.md 를 읽고, 거기 적힌 조사 범위대로
웹에서 최신 사례를 찾아서 report/경쟁사-리서치.md 로 작성해줘.

사례는 반드시 3건, 각각 출처와 날짜를 붙이고,
마지막에 "우리 제안에 반영할 인사이트" 3가지로 마무리해줘.
지어낸 사례는 절대 넣지 마.
```

### 관찰 포인트 — 스스로 점검할 것 (정답이 없는 리서치라 체크리스트로 대체)

- [ ] 사례 3건 모두 **출처(매체명·링크)와 날짜**가 붙어 있는가
- [ ] &quot;~인 것으로 보인다&quot;, &quot;확인 필요&quot; 처럼 **불확실한 부분을 숨기지 않고** 표시했는가
- [ ] 세 사례가 **서로 다른 각도**(개인화 · 크리에이티브 · 리테일 미디어)를 각각 다루는가, 아니면 한쪽에 쏠렸는가
- [ ] &quot;인사이트&quot;가 사례를 그대로 요약한 것이 아니라 **우리 제안에 무엇을 하라는 제안**으로 이어지는가
- [ ] 존재를 확인할 수 없는 브랜드·수치를 지어내지 않았는가 (가장 흔한 실패입니다)

### 왜 Level 2·3으로 안 가는지 직접 느껴 보기

`/clear` 후 같은 프롬프트를 한 번 더 돌려 보세요. 이번엔 조사 범위를
&quot;AI 개인화&quot; 대신 &quot;라이브커머스 결합 캠페인&quot;으로 바꿔서 넣어 보세요.

- **매번 조사 범위 자체가 달라집니다.** 2차시의 매체 용어집처럼 &quot;한 번 만들어 두면
  계속 쓰는 규칙&quot;이 이 업무에는 거의 없습니다 — 표준화할 대상이 없는 것입니다.
- 조사 담당을 3명으로 나눠도(Level 2) 각자 다른 사례를 찾아올 뿐, **검증 비용만 늘고
  깊이의 이득은 트렌드 리포트만큼 크지 않습니다** — 애초에 사례가 1인당 1건이면 충분하기 때문입니다.
- 그래서 3차시 사례에서 정하늘 대리는 이 업무를 **Level 1에 남겨 두기로 결정**했습니다.

## 5. 뒤 차시와의 연결

이 업무는 &quot;시스템화하지 않기로 결정한 사례&quot;로 남습니다. 4~6차시의 하네스·스펙·Tool은
전부 **주간 리포트**(반복 업무) 쪽에 투입됩니다. 하네스를 어디에 쓸지 **고르는 것**도
실력이라는 3차시의 핵심 메시지를 이 폴더 안에서 직접 확인한 것입니다.
