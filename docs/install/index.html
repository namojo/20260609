공통 준비 · macOS 시작하기 →
🔑

시작 전에 구독을 먼저 확인하세요. 이 과정의 실습에는 Claude Pro / Max / Team / Enterprise 중 하나가 필요합니다. 무료 플랜으로는 Claude Code를 쓸 수 없습니다. claude.ai → 왼쪽 아래 계정 메뉴에서 플랜을 확인하세요. API Key는 필요하지 않습니다.

1. 전체 설치 지도

문서는 세 개입니다. 1번만 필수이고, 2·3번은 해당 모듈을 실습할 때만 하면 됩니다.

  • 1
    공통 준비 — 모든 실습의 출발점

    Git · Claude Code · 에이전트 팀 · Harness 플러그인 · 실습 저장소까지 한 번에 준비합니다.

    끝나면: Claude Code에서 하네스 구성해줘 가 동작합니다.

    필수⏱ 25~35분WindowsmacOS
  • 2
    Codex CLI — 두 번째 AI 붙이기

    ChatGPT Plus 구독으로 OpenAI 터미널 AI를 붙입니다. 같은 지시서를 두 도구에 주고 결과를 비교하는 실습에 씁니다.

    구독이 없으면 건너뛰어도 됩니다. 비교 실습은 관찰 학습으로 대체할 수 있습니다.

    선택⏱ 10~15분🔑 ChatGPT Plus 이상
  • 3
    MCP 서버 (Tool) — 나만의 도구 붙이기

    파이썬 40줄짜리 계산기를 Claude Code와 Codex 양쪽에 붙입니다. "AI가 못 하는 정확한 계산은 코드에 맡긴다" 를 손으로 확인합니다.

    Tool 모듈을 실습할 때만 필요합니다. Python은 이 문서에서만 씁니다.

    모듈 전용⏱ 20~30분🐍 Python 3.10+

교육 전날까지 1번(공통 준비)만이라도 끝내 두세요. 나머지는 해당 모듈 직전에 해도 늦지 않습니다.

4. 준비 완료 체크리스트

공통 준비를 마쳤다면 아래가 모두 되어 있어야 합니다. 하나라도 비면 해당 문서의 문제 해결 절을 보세요.

  • Claude Pro 이상 구독 확인
  • git --version 이 버전 번호를 출력
  • claude --version 이 버전 번호를 출력
  • 에이전트 팀 환경변수가 1 (Windows echo $env:CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS · Mac echo $CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS)
  • C:\harness-edu(Mac은 ~/harness-edu) 폴더 존재
  • claude 실행 후 한국어로 대화 성공
  • /plugin 목록에 harness, document-skills 표시
  • 입력창에 하네스 구성해줘 → 되묻는 질문이 옴

5. 자동 점검 스크립트 (Windows · 선택)

설치를 마친 뒤 빠진 게 없는지 한 번에 점검하는 스크립트입니다. 빠진 항목만 설치하며, 여러 번 실행해도 안전합니다.

PowerShell에 붙여넣기 ①
cd "$env:USERPROFILE\Downloads"
PowerShell에 붙여넣기 ②
irm https://namojo.github.io/harness-edu/install/setup-windows.ps1 -OutFile setup-windows.ps1
PowerShell에 붙여넣기 ③
Unblock-File .\setup-windows.ps1
PowerShell에 붙여넣기 ④
.\setup-windows.ps1

자세한 옵션과 실행 결과 예시는 공통 준비 · Windows 9-A절에 있습니다. macOS는 명령이 이미 한 줄씩이라 별도 스크립트를 만들지 않았습니다.

6. 자주 묻는 질문

개발을 전혀 모르는데 따라 할 수 있나요?

네. 이 가이드는 터미널을 처음 여는 분을 기준으로 썼습니다. 명령을 이해할 필요 없이 복사해서 붙여넣으면 되고, 각 단계마다 화면에 무엇이 나와야 정상인지 그림처럼 적어 두었습니다. 막히는 지점은 대부분 "창을 새로 열지 않아서" 생기므로, 문서가 시키는 대로 창을 닫았다 여는 것만 지켜도 대부분 해결됩니다.

Claude 구독이 꼭 필요한가요?

필요합니다. Claude Code는 Pro 이상 구독에서 동작하며 무료 플랜은 지원하지 않습니다. 회사 계정(Team/Enterprise)이라면 관리자가 Claude Code 사용을 허용했는지 미리 확인하세요.

Codex(ChatGPT)까지 있어야 하나요?

아닙니다. 대부분의 모듈은 Claude Code만으로 진행됩니다. Codex는 "같은 지시서를 다른 AI에 줬을 때 결과가 어떻게 달라지는가" 를 직접 보기 위한 선택 항목입니다.

회사 보안 때문에 설치가 막히면요?

보안 프로그램을 끄지 마세요. IT 담당자에게 필요한 것만 요청하면 됩니다 — github.com·claude.ai 접근, 그리고 Windows라면 PowerShell CurrentUser 실행 정책 RemoteSigned 허용. 그래도 어려우면 교육 담당자에게 알려 주세요.

실제 업무 파일로 실습해도 되나요?

하지 마세요. 실습 폴더에는 가상 데이터만 넣습니다. AI 도구는 실행한 폴더의 파일을 읽을 수 있습니다. 실 데이터 적용은 교육 이후 IT·보안 검토를 거쳐 진행합니다.

설치한 것을 나중에 지울 수 있나요?

가능합니다. 각 문서의 제거·되돌리기 절에 원래 상태로 되돌리는 명령이 정리되어 있습니다. 실습 폴더는 통째로 삭제하면 됩니다.

7. 설치가 끝났다면

다음커리큘럼 시작첫 모듈부터 순서대로 진행하세요. 혼자 할 때자가 학습 가이드무엇을 어떤 순서로, 무엇을 관찰할지 안내합니다. 저장소GitHub실습 파일과 모듈 교안 원본.

설치 중 막히면 교육 전날까지 담당자에게 알려 주세요. Windows 점검 스크립트를 돌렸다면 %USERPROFILE%\harness-setup-logs\ 의 로그 파일을 함께 보내 주시면 원인 파악이 빠릅니다.
