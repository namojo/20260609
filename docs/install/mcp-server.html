1. 이 도구는 무엇인가

MCP 서버 는 AI에게 붙이는 계산기입니다. 이 과정에서 배우는 세 축 중 마지막인 Tool 에 해당합니다.

축무엇인가형태같은 질문에 같은 답?
Agent역할·경계 (누가)지시문 파일—
Skill지식·절차 (무엇을·어떻게)AI가 읽는 문서✗ 모델이 해석
Tool실행 수단 (무엇으로)실제 코드✓ 항상 같음

왜 필요한지는 한 번 보면 바로 이해됩니다. "B라인 어제 OEE(설비종합효율) 알려줘" 를 물었을 때—

도구 없이 — AI가 암산
가동률 0.75쯤, 성능 0.94쯤... OEE 대략 70% 안팎으로 보입니다
도구 있이 — 코드가 계산
{ "availability": 0.75, "performance": 0.9444, "quality": 0.9853,
  "oee": 0.6979, "oee_pct": "69.8%", "bottleneck": "가동률" }

앞은 그럴듯하지만 검증할 수 없고 매번 값이 다릅니다. 뒤는 몇 번을 돌려도 69.8% 이고, 병목이 가동률이라는 진단까지 코드가 계산합니다.

왜 MCP인가: MCP(Model Context Protocol)는 Anthropic이 공개한 오픈 표준입니다. 서버 하나를 만들어 두면 Claude Code도, Codex도, 앞으로 나올 다른 AI도 그대로 씁니다. 사내 계산 도구를 "도구별로 다시 만들지 않는" 방법이고, 이것이 이 실습의 핵심 메시지입니다.

이 실습에서 붙이는 서버(production-metrics)에는 도구가 3개 있습니다.

도구하는 일
list_records조회 가능한 라인·날짜 목록
compute_oee지정한 라인·날짜의 OEE 계산 + 병목 진단
defect_ppm불량률(ppm) 계산

2. 설치 전 확인

항목필요한 것확인·대처
선행 설치공통 준비 완료 + 실습 저장소Windows / macOS
Python3.10 이상3-1절에서 확인 (없으면 설치 안내)
Codex (선택)같은 도구를 Codex에도 붙일 때만Codex CLI 설치가이드
관리자 권한필요 없음가상환경(.venv)은 실습 폴더 안에 만듭니다
💡

Python은 이 문서에서만 씁니다. 다른 모듈(엑셀·문서·하네스 실습)에는 필요하지 않습니다. 이 모듈을 건너뛰면 Python도 설치하지 않아도 됩니다.

가상환경(.venv)이 뭔가요: 이 실습에만 쓰는 격리된 파이썬 방입니다. 내 PC의 다른 파이썬 환경을 건드리지 않고, 실습이 끝나면 폴더만 지우면 완전히 정리됩니다. 그래서 회사 노트북에서도 안전합니다.

3-3. 가상환경 만들기

본인 OS 것만 실행하세요. Windows에서 python3 를 쓰면 별칭 오류가 나고, macOS에서 python 을 쓰면 명령을 찾지 못합니다.

Windows

Windows · PowerShell
python -m venv .venv

macOS

macOS · 터미널
python3 -m venv .venv
👀

예상 결과: 아무 메시지 없이 프롬프트가 돌아오고, 현재 폴더에 .venv 폴더가 생깁니다. 터미널에서는 "조용한 성공"이 정상입니다.

💡

"가상환경 켜기(activate)" 는 하지 않습니다. 켜는 대신, 다음 단계부터 가상환경 안의 파이썬을 직접 지정합니다. 이유는 두 가지입니다.

  • Windows에서 activate 는 실행 정책에 막히는 경우가 많습니다
  • 터미널을 새로 열면 켜둔 것이 꺼지고, 그 상태로 다음 명령을 실행하면 ModuleNotFoundError 가 납니다

직접 지정하면 창을 새로 열어도, 어느 폴더에서 실행해도 항상 같은 파이썬이 쓰입니다.

3-4. 필요한 패키지 설치

가상환경 안의 파이썬으로 설치합니다. 앞의 .\.venv\Scripts\python.exe 부분이 "이 파이썬으로" 라는 뜻입니다.

Windows

Windows · PowerShell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

macOS

macOS · 터미널
./.venv/bin/python -m pip install -r requirements.txt
👀

예상 결과: 여러 줄이 흐르고 마지막에 Successfully installed mcp-... 가 나옵니다. 1~3분.

⚠️

이렇게 나오면 오류: ERROR: Could not find a version... 또는 시간 초과 → 사내 프록시가 파이썬 저장소를 막고 있습니다. 휴대폰 테더링으로 재시도하고, 계속 막히면 IT 담당자에게 pypi.org 접근을 요청하세요.

👀

설치된 버전 확인 — 1.x 여야 합니다.

Windows · PowerShell
.\.venv\Scripts\python.exe -m pip show mcp
macOS · 터미널
./.venv/bin/python -m pip show mcp
예상 화면
Name: mcp
Version: 1.19.0        ← 1 로 시작해야 합니다
📌

왜 버전을 1.x 로 고정하나 — MCP 파이썬 패키지 2.0 부터 FastMCP 의 위치가 바뀌었습니다.

버전FastMCP 위치
1.xmcp.server.fastmcp ← 이 실습의 server.py 가 쓰는 경로
2.xmcp.server.mcpserver (이름이 바뀌고 fastmcp 는 삭제됨)

그래서 requirements.txt 에 mcp[cli]>=1.2.0,<2 로 못 박아 두었습니다. 이 파일을 그대로 쓰면 문제가 생기지 않습니다.

3-5. 도구가 실제로 계산하는지 먼저 확인

AI에 붙이기 전에, 계산 자체가 맞는지 확인합니다. (AI 없이 코드만 실행) 여기서도 같은 파이썬을 지정합니다.

Windows

PowerShell에 붙여넣기
.\.venv\Scripts\python.exe -c "from server import compute_oee; print(compute_oee('B','2026-07-14'))"

macOS

터미널에 붙여넣기
./.venv/bin/python -c "from server import compute_oee; print(compute_oee('B','2026-07-14'))"
👀

예상 결과: 계산 결과가 그대로 출력됩니다.

예상 화면
{'availability': 0.75, 'performance': 0.9444, 'quality': 0.9853,
 'oee': 0.6979, 'oee_pct': '69.8%', 'bottleneck': '가동률'}

몇 번을 실행해도 값이 같습니다. 이것이 Skill(암산)과 결정적으로 다른 점입니다.

⚠️

ModuleNotFoundError: No module named 'mcp' 가 나오면 — 패키지가 다른 파이썬에 설치된 것입니다. 아래 한 줄로 지금 쓰는 파이썬과 설치 상태를 함께 확인하세요.

Windows — 진단
.\.venv\Scripts\python.exe -c "import sys; print(sys.executable); import mcp; print('mcp OK')"
macOS — 진단
./.venv/bin/python -c "import sys; print(sys.executable); import mcp; print('mcp OK')"

경로가 .venv 안을 가리키고 mcp OK 가 나오면 정상입니다. 여기서도 ModuleNotFoundError 가 나면 3-4절을 다시 실행하세요 (같은 명령이므로 여러 번 해도 안전합니다). 자세한 원인은 문제 해결 ②.

💡

파일이 없다고 나오면 tool/mcp-server 폴더가 아닌 곳에서 실행한 것입니다. 3-2절의 cd 명령으로 다시 들어가세요. (ls 를 쳤을 때 server.py 가 보여야 합니다)

5. 초기 설정·연동

5-1. 도구 승인 화면에서 무엇을 위임하는가

AI가 도구를 처음 호출할 때 승인을 물어봅니다. 이때 위임하는 것은 "이 폴더의 CSV를 읽어 계산하는 코드를 실행할 권한" 입니다. 외부로 데이터를 보내지 않고, 계산은 내 PC에서 일어납니다.

안전 원칙
① 이 서버는 tool/mcp-server/data/production.csv 가상 데이터만 읽습니다.
② 실제 생산·재무 데이터를 이 폴더에 복사해 넣지 않습니다. 실습은 가상 데이터로 충분합니다.
③ 사내 실 데이터에 붙이는 것은 교육 이후 IT·보안 검토를 거친 뒤 진행합니다.

5-2. 같은 도구를 Codex에도 붙이기 (선택)

Codex에는 스코프 개념이 없고 등록하면 전역으로 적용됩니다. MCP가 오픈 표준이라는 것을 여기서 확인합니다. 코드를 한 줄도 바꾸지 않고 다른 AI에 붙입니다. (Codex CLI 를 설치한 경우에만)

Windows · PowerShell
codex mcp add production-metrics -- python "C:\harness-edu\tool\mcp-server\server.py"
macOS · 터미널
codex mcp add production-metrics -- python3 ~/harness-edu/tool/mcp-server/server.py
등록 확인
codex mcp list
🔎

관찰 포인트: 스킬(문서)은 도구마다 복사해야 했지만, Tool은 하나의 서버를 양쪽이 각자 등록해 공유합니다. 계산 로직의 원본이 한 곳뿐이라 고칠 때도 한 번만 고치면 됩니다.

예상 결과: AI가 compute_oee 를 호출하고(화면에 도구 호출 표시가 보입니다) 69.8% 를 답합니다. 승인을 물으면 승인하세요.

② 도구 + 해석을 함께
production-metrics 도구로 07-14 A·B·C 세 라인의 OEE를 구하고,
가장 낮은 라인의 병목이 무엇인지, 개선하려면 어디를 봐야 하는지 정리해줘.
👀

예상 결과: 도구를 세 번 호출해 정확한 값을 받아 온 뒤, 거기에 해석만 얹습니다. — "정확한 산수는 도구, 해석은 모델" 이라는 분업이 눈으로 보입니다.

⚠️

AI가 도구를 안 부르고 직접 암산하려 하면: "compute_oee 도구를 사용해서" 라고 명시하세요. 도구 설명이 구체적일수록 자동 호출이 잘 됩니다 — 이것이 도구 설명문(docstring)도 지시서인 이유입니다.

7. 문제 해결

① ModuleNotFoundError: No module named 'mcp'

가장 흔한 오류입니다. 패키지가 없는 게 아니라, 패키지를 설치한 파이썬과 지금 실행한 파이썬이 다른 것입니다.

이런 경우해결
mcp.server.fastmcp 를 못 찾는다
(mcp 자체는 설치됨)		2.x 가 설치된 것입니다. 2.0 부터 이 경로가 mcp.server.mcpserver 로 바뀌었습니다. 아래 명령으로 1.x 로 되돌리세요.
그냥 python 으로 실행했다가상환경 파이썬을 지정해야 합니다 — .\.venv\Scripts\python.exe (mac: ./.venv/bin/python)
터미널을 새로 열었다가상환경을 켜 뒀더라도 새 창에서는 꺼집니다. 지정 방식을 쓰면 이 문제가 없습니다
pip install 이 다른 파이썬에 설치했다3-4절 명령(...python.exe -m pip install ...)으로 다시 실행하세요
AI가 도구를 부를 때만 실패한다등록이 python server.py 로 되어 있습니다. 3-6절의 전체 경로 방식으로 재등록

진단 한 줄 — 지금 쓰는 파이썬 위치와 설치 상태를 함께 봅니다.

Windows · PowerShell
.\.venv\Scripts\python.exe -c "import sys; print(sys.executable); import mcp; print('mcp OK')"
macOS · 터미널
./.venv/bin/python -c "import sys; print(sys.executable); import mcp; print('mcp OK')"
👀

예상 결과: 경로가 .venv 안을 가리키고 mcp OK 가 나옵니다. 여기서도 실패하면 3-4절을 다시 실행하세요(여러 번 해도 안전).

🔧

No module named 'mcp.server.fastmcp' 인 경우 (2.x 설치됨) — 아래 한 줄로 1.x 로 맞춥니다. 예전에 받은 requirements.txt 를 쓰고 있어도 이 명령은 버전을 직접 지정하므로 확실합니다.

Windows · PowerShell
.\.venv\Scripts\python.exe -m pip install "mcp[cli]>=1.2.0,<2"
macOS · 터미널
./.venv/bin/python -m pip install "mcp[cli]>=1.2.0,<2"

끝나면 pip show mcp 로 Version: 1.x 인지 확인하고, 3-5절 검증을 다시 실행하세요. 저장소를 최근에 받았다면 requirements.txt 에 이미 고정되어 있어 3-4절을 다시 실행하는 것만으로도 해결됩니다.

⚠️

.venv\Scripts\python.exe 자체가 없다고 나오면 가상환경이 안 만들어진 것입니다. 3-2절에서 tool/mcp-server 폴더에 들어와 있는지 확인하고 3-3절을 다시 하세요.

② 도구 목록에 안 뜨거나 연결 실패(failed)

증상원인 · 해결
spawn python ENOENTpython 을 찾지 못했습니다. 3-6절의 전체 경로 방식으로 다시 등록하세요.
목록에 안 뜸등록 후 Claude Code 재시작이 필요합니다. 먼저 claude mcp list 로 등록 여부를 확인하세요.
ModuleNotFoundError: mcp서버를 실행하는 파이썬에 패키지가 없습니다 → 문제 해결 ①
이 폴더에서만 보임local 스코프로 등록됐습니다. claude mcp remove production-metrics 후 --scope user 로 재등록
데이터를 못 찾음server.py 는 자기 위치 기준으로 data/production.csv 를 찾습니다. 파일을 옮기지 마세요.

③ 등록을 지우고 다시 하고 싶습니다

터미널에 붙여넣기
claude mcp remove production-metrics

이후 3-6절을 다시 실행합니다. claude mcp get production-metrics 로 현재 등록 내용을 볼 수 있습니다.

④ Windows: Activate.ps1 을 로드할 수 없습니다

이 문서는 가상환경을 켜지 않고 파이썬을 직접 지정하므로 이 오류를 만나지 않습니다. 다른 자료를 보고 activate 를 시도했다면, 켜지 말고 3-4절 방식(.\.venv\Scripts\python.exe -m pip ...)을 쓰면 됩니다.

그래도 켜고 싶다면 아래로 본인 계정 범위만 완화합니다(Y 승인). 회사 정책으로 실패하면 우회하지 말고 IT 담당자에게 요청하세요.

Windows · PowerShell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

⑤ 한글 데이터가 깨져 보입니다

  • Windows 11의 터미널(Windows Terminal) 로 실행하세요. 데이터 파일 자체는 UTF-8로 정상입니다.

8. 제거·연동 해제

1) 등록 해제

터미널에 붙여넣기
claude mcp remove production-metrics

Codex에도 붙였다면: codex mcp remove production-metrics

2) 가상환경 삭제 — tool/mcp-server/.venv 폴더를 지우면 설치한 패키지가 모두 사라집니다. 시스템 파이썬은 그대로입니다.

Windows · PowerShell
Remove-Item -Recurse -Force .\.venv
macOS · 터미널
rm -rf .venv

3) Python 제거 (원한다면) — Windows: 설정 → 앱 → 설치된 앱 → Python → 제거. macOS: 시스템 파이썬은 지우지 마세요.

9. 다른 연결 방법 (필요할 때만)

A. .mcp.json 파일로 등록 (팀 공유용 · project 스코프)

프로젝트 루트에 아래 파일을 두면, 저장소를 받은 팀원 모두가 같은 도구를 씁니다. 경로는 각자 환경에 맞게(절대경로 권장) 조정합니다.

.mcp.json
{
  "mcpServers": {
    "production-metrics": {
      "command": "python",
      "args": ["tool/mcp-server/server.py"]
    }
  }
}

Claude Code를 다시 시작하면 인식하며, 처음 로드 시 신뢰 여부를 물어볼 수 있습니다.

B. 원격(HTTP) 서버 — 심화

지금은 내 PC에서 python server.py 를 띄우는 방식입니다. 팀 전체가 공유하려면 서버를 HTTP로 올리고 아래처럼 등록합니다. 로컬 계산기가 사내 API로 승격되는 단계입니다.

터미널에 붙여넣기
claude mcp add my-remote --transport http https://mcp.example.com/mcp
