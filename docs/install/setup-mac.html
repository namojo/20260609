1. 이 문서는 무엇인가

이 과정에서 우리는 AI에게 일을 한 번 시키는 것이 아니라, 여러 번 같은 품질로 시키는 구조를 만듭니다. 그 구조를 하네스(Harness) 라고 부릅니다.

필요한 것왜이 문서에서
Claude Code하네스가 실행되는 작업장. 터미널에서 대화하는 AI설치 + 로그인
에이전트 팀 기능전문가 여러 명이 동시에 일하게 하는 스위치환경변수 1줄
Harness 플러그인"하네스 구성해줘" 한마디로 팀을 설계해 주는 도구플러그인 설치
실습 저장소생산 보고서 엑셀·샘플 데이터 등 실습 파일git clone

이 과정에서 설치하지 않는 것: Node.js, bun, Homebrew(선택), Docker, 별도 편집기.
Claude Code는 자체 실행 파일로 설치되므로 개발 언어 런타임이 필요하지 않습니다. (Python은 3번째 설치가이드 MCP 서버 에서만 쓰며, macOS에는 이미 들어 있습니다.)

3-5. 에이전트 팀 기능 켜기 (하네스 필수 조건)

하네스는 전문가 에이전트 여러 명이 팀으로 협업하는 기능을 씁니다. 기본이 꺼져 있어 한 번 켜 주어야 합니다.

터미널에 붙여넣기
echo 'export CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1' >> ~/.zshrc
👀

예상 결과: 아무 메시지 없이 프롬프트로 돌아옵니다. 터미널에서는 "조용한 성공"이 정상입니다.

터미널을 닫고 새로 열어 값을 확인합니다.

터미널에 붙여넣기
echo $CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS
👀

예상 결과: 1 한 글자.

⚠️

비어 있으면: 오래된 Mac에서 기본 셸이 bash 일 수 있습니다. 같은 명령에서 ~/.zshrc 를 ~/.bash_profile 로 바꿔 다시 실행하세요. 현재 셸은 echo $SHELL 로 확인합니다.

3-6. 실습 저장소 받기 (실습 폴더 만들기)

☁️

데스크탑이나 서류 폴더에 받지 않습니다. macOS의 "데스크탑 및 서류 폴더" iCloud 동기화가 켜져 있으면 그 두 폴더가 클라우드로 올라가고, 저장소를 그 안에 두면 동기화가 .git 파일을 건드려 오류가 납니다. 파일이 "용량 확보"로 내려받기 대기 상태가 되면 AI가 읽지 못합니다.

그래서 홈 폴더 바로 아래(~/harness-edu)에 받습니다. 홈 폴더 자체는 동기화 대상이 아닙니다.

터미널에 붙여넣기
git clone https://github.com/namojo/harness-edu.git ~/harness-edu
👀

예상 결과: 진행 표시가 흐르고 홈 폴더에 harness-edu 가 생깁니다.

예상 화면
Cloning into '/Users/본인이름/harness-edu'...
Receiving objects: 100% (300/300), 6.20 MiB | 5.30 MiB/s, done.

경로에 Desktop 이나 Mobile Documents(iCloud) 가 없어야 정상입니다.

이제 그 폴더로 이동합니다. 실습은 항상 이 폴더 안에서 합니다.

터미널에 붙여넣기
cd ~/harness-edu && pwd
👀

예상 결과: /Users/본인이름/harness-edu 가 출력됩니다.

⚠️

이미 데스크탑에 받았다면 아래로 옮기세요.

터미널에 붙여넣기
[ -d ~/Desktop/harness-edu ] && mv ~/Desktop/harness-edu ~/harness-edu && echo "옮김 완료" || echo "옮길 것이 없습니다"

파인더에서 이 폴더를 열려면:

터미널에 붙여넣기
open ~/harness-edu

3-8. Harness 플러그인 설치 (스코프 선택 주의)

여기서부터는 터미널이 아니라 Claude Code 입력창에 입력합니다.

📌

설치 중에 "어느 범위에 설치할까요?" 화면이 나옵니다. 반드시 User scope 를 고르세요.

선택지뜻이 과정에서
User scope
사용자 범위		내 계정의 모든 폴더에서 쓸 수 있게 설치✅ 이것을 선택
Project scope이 폴더에서만. .claude/settings.json 에 기록되어 팀원과 공유됨❌ 다른 폴더로 옮기면 안 됩니다
Local scope이 폴더에서만, 나만❌ 같은 이유로 부적합

왜 User scope인가: 이 과정은 폴더를 계속 옮겨 다닙니다 — ~/harness-edu/xlsx(1차시), ad(2차시), codex(3차시), harness·my-harness(4차시), map(5차시), tool/mcp-server(6차시), my-work/...(7차시). Project·Local로 설치하면 설치한 그 폴더에서만 동작해서, 4차시에 새 폴더를 만든 순간 하네스 구성해줘 가 먹히지 않습니다.

Claude Code 입력창에 붙여넣기 ①
/plugin marketplace add revfactory/harness
Claude Code 입력창에 붙여넣기 ②
/plugin install harness@harness-marketplace
👀

예상 결과: 플러그인 상세 화면에서 설치 범위 목록이 나옵니다. 방향키로 User 선택 → Enter. 설치 후 마지막 줄을 확인하세요.

둘 중 하나가 나옵니다
Plugin is now active.              → 바로 쓸 수 있습니다
Run /reload-plugins to activate.   → 아래 명령을 한 번 실행하세요
위에서 "Run /reload-plugins" 라고 나왔을 때만
/reload-plugins

이어서 문서 작업용 Anthropic Skills 플러그인도 설치합니다. 이때도 User scope를 고릅니다.

Claude Code 입력창에 붙여넣기 ③
/plugin marketplace add anthropics/skills
Claude Code 입력창에 붙여넣기 ④ — 여기서도 User scope
/plugin install document-skills@anthropic-agent-skills

설치 범위가 맞는지 확인하기

입력창에서 /plugin → Installed 탭을 보면 목록이 범위별로 묶여 있습니다. 두 플러그인이 User 그룹에 있으면 정상입니다. 잘못 설치했다면 /plugin uninstall harness@harness-marketplace 로 지우고 다시 설치하면서 User를 고르세요.

💡

대화 없이 한 번에 설치하려면 — 터미널에서 아래를 실행하면 스코프 질문 없이 User 범위로 설치됩니다 (셸 명령의 기본값이 User).

터미널에 붙여넣기 (선택)
claude plugin marketplace add revfactory/harness
claude plugin install harness@harness-marketplace --scope user
claude plugin marketplace add anthropics/skills
claude plugin install document-skills@anthropic-agent-skills --scope user

5-3. 실습 파일 여는 방법

실습 폴더에는 여러 형식의 파일이 들어 있습니다. 대부분 추가 설치 없이 볼 수 있지만, .md 파일은 미리보기로 열면 서식이 보이지 않습니다.

파일무엇어떻게 여나
.md교안 · 용어집 · AI가 만든 리포트텍스트 편집기로도 읽힙니다(그냥 텍스트). 표·제목이 정돈된 화면으로 보려면 아래 ① 또는 ②

.hwpx4차시 과업지시서Mac용 한컴오피스 또는 웹 한글. 직접 열지 않아도 됩니다 — AI가 읽습니다

① 설치 없이 — GitHub 웹에서 보기 (권장)

교안과 .md 파일은 GitHub 웹페이지에서 가장 잘 읽힙니다. 표와 제목이 정돈된 상태로 보이고, 설치가 필요 없습니다.

주소창에 붙여넣기
https://github.com/namojo/harness-edu

내 PC에서 만든 파일이 아니라 원본 교안을 볼 때 이 방법이 가장 빠릅니다.

② 내가 만든 파일까지 편하게 — VS Code 설치 (선택)

AI가 만들어 준 .md 리포트를 보기 좋게 열고, CSV·JSON도 한글이 깨지지 않게 보려면 무료 편집기 하나가 편합니다. 필수는 아닙니다.

code.visualstudio.com 에서 Mac용을 받아 응용 프로그램 폴더로 끌어다 놓으면 끝입니다. Homebrew를 쓰신다면 brew install --cask visual-studio-code 도 됩니다.

💡

쓰는 법은 세 가지만

  • 실습 폴더 전체 열기 — PowerShell에서 code C:\harness-edu
  • .md 파일을 보기 좋게 보기 — 파일을 열고 Command+Shift+V
  • 왼쪽 목록에서 파일을 클릭하면 바로 내용이 보입니다

편집기지만 여기서는 읽는 용도로만 씁니다. 코드를 쓸 일은 없습니다.

③ 엑셀에서 CSV 한글이 깨질 때

실습 CSV는 UTF-8 형식입니다. 파일을 더블클릭해서 열면 엑셀이 다른 형식으로 잘못 읽어 ë£¨ë¯¸ì—ë¥´ 처럼 보일 수 있습니다. 아래 순서로 열면 정상입니다.

1엑셀을 먼저 실행 (빈 통합 문서)
2파일 → 가져오기 → CSV 파일 선택
3파일 원본(인코딩)을 유니코드(UTF-8) 로
4미리보기에서 한글이 정상이면 완료

넘버스는 UTF-8 CSV를 대개 그대로 잘 읽습니다.

VS Code로 열면 이 과정이 필요 없습니다.

🤖

파일을 못 열어도 실습은 진행됩니다. Claude Code가 엑셀·워드·PPT·한글 파일을 직접 읽습니다(그래서 document-skills 플러그인을 설치했습니다). 내용이 궁금하면 열지 말고 이렇게 물어보세요.

이 폴더의 파일들이 각각 무슨 내용인지 한 줄씩 정리해줘.

안전 원칙
① 실제 업무 파일이 있는 폴더에서 실습하지 않습니다. 항상 harness-edu 폴더에서 실행하세요.
② AI가 파일을 수정·삭제하려 할 때 승인 여부를 물어봅니다. 내용을 읽고 판단하세요.
③ 회사 보안 프로그램이 설치를 막으면 끄지 말고 IT 담당자에게 문의합니다.

지금 이 폴더에 어떤 파일과 폴더가 있는지 한국어로 요약해줘.
👀

예상 결과: xlsx, tool, harness, codex 같은 실습 폴더 목록이 한국어로 나옵니다.

Claude Code 입력창에 붙여넣기
하네스 구성해줘
👀

예상 결과: "어떤 도메인의 하네스를 만들까요?" 처럼 되묻는 질문이 옵니다. 이 질문이 오면 플러그인이 정상 작동하는 것이고, 설치는 여기서 끝입니다.

🚪

여기서 답하지 말고 빠져나옵니다. 지금은 동작만 확인하는 단계입니다. 도메인을 답하면 실제로 에이전트 팀을 만들기 시작해 시간이 오래 걸립니다.

빠져나오는 순서

  1. ESC 키를 한 번 누릅니다. 질문·선택 목록 화면이 닫히고 입력창으로 돌아옵니다.
  2. 화면이 그대로면 ESC 를 한 번 더 누릅니다. (질문이 여러 겹일 수 있습니다)
  3. 맨 아래에 입력창 표시 > 가 보이면 아래를 입력하고 Enter.
입력창으로 돌아온 뒤
/exit

주의: 선택 목록이 떠 있는 상태에서 /exit 를 치면 명령이 아니라 답변으로 입력됩니다. 반드시 ESC 로 입력창에 돌아온 뒤에 치세요.

⚠️

그래도 빠져나오지 못하면: Ctrl+C 를 두 번 누릅니다(Mac도 Control 키). 그러면 Claude Code가 종료되고 터미널 프롬프트로 돌아옵니다. 이미 팀을 만들기 시작했다면 ESC 로 작업을 중단한 뒤 /exit 하세요. 중간에 끊어도 설치에는 아무 문제가 없습니다.

7. 문제 해결

① command not found: claude

  • 원인: 설치는 됐지만 실행 경로가 셸에 등록되지 않았습니다.
  • 해결 1: 터미널을 Command+Q 로 완전히 종료하고 새로 열어 재확인.
  • 해결 2: 그래도 안 되면 아래를 실행한 뒤 새 창을 엽니다.
터미널에 붙여넣기
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc

② zsh: permission denied 또는 설치가 중간에 멈춤

  • 확인: 명령을 sudo 없이 실행했는지. Claude Code 설치에 관리자 권한은 필요하지 않으며, sudo 로 설치하면 권한이 꼬입니다.
  • 해결: 홈 폴더 권한 문제라면 ls -ld ~/.local 로 소유자가 본인인지 확인하세요.

③ 로그인은 됐는데 "구독이 필요합니다"

  • 원인: 무료 플랜 계정으로 로그인했습니다. Claude Code는 Pro 이상이 필요합니다.
  • 해결: 입력창에서 /logout → claude 재실행 → 구독 계정으로 로그인.

④ /plugin marketplace add 가 실패합니다

  • git --version 이 동작하는지 확인 (플러그인은 Git으로 내려받습니다).
  • 저장소 이름 확인 — revfactory/harness, anthropics/skills.
  • 사내 방화벽이 github.com 을 막을 수 있습니다. 휴대폰 테더링으로 재시도.

⑤ 다운로드가 멈추거나 연결이 안 됩니다

💡

터미널에서 curl https://claude.ai 가 403 을 돌려줘도 정상입니다. claude.ai 는 자동화된 요청을 봇으로 보고 거부합니다. 브라우저에서 열리는지만 확인하면 됩니다.

  • 브라우저에서 https://claude.ai, https://github.com 이 열리는지 확인합니다.
  • 사내 Wi-Fi 대신 휴대폰 테더링으로 재시도(교육장에서 가장 빠른 방법).
  • 설치 명령은 여러 번 재실행해도 안전합니다(↑ → Enter).
  • 계속 막히면 백신을 임의로 끄지 말고 IT 담당자에게 문의하세요.

⑥ 에이전트 팀이 만들어지지 않습니다

  • 새 터미널에서 echo $CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS 가 1 인지 확인합니다.
  • 비어 있으면 3-5절을 다시 하고 반드시 창을 새로 열어 claude 를 실행합니다.

8. 제거·되돌리기

1) 플러그인 제거 — Claude Code 입력창에서 /plugin uninstall harness@harness-marketplace

2) Claude Code 제거

터미널에 붙여넣기
rm -f ~/.local/bin/claude
rm -rf ~/.local/share/claude

3) 설정·대화 기록까지 지우기 (선택 — 되돌릴 수 없습니다)

터미널에 붙여넣기
rm -rf ~/.claude ~/.claude.json

4) 에이전트 팀 설정 되돌리기 — ~/.zshrc 를 열어 export CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 줄을 지웁니다. (편집: open -e ~/.zshrc)

5) 실습 폴더 삭제 — ~/harness-edu 를 휴지통으로 옮기고 휴지통을 비웁니다.

9. 다른 설치 방법 (본문이 막힐 때만)

  • Homebrew: 이미 brew를 쓰고 있다면 brew install --cask claude-code. 단 자동 업데이트가 되지 않아 brew upgrade claude-code 로 직접 갱신해야 합니다.
  • npm: Node.js 22 이상이 이미 있는 분만 npm install -g @anthropic-ai/claude-code. Node.js를 새로 깔 필요는 없습니다.
  • 자동 점검 스크립트: Windows 전용입니다. macOS는 위 명령이 이미 한 줄씩이라 별도 스크립트를 만들지 않았습니다.
