1. 문제 상황 — 같은 양식, 다른 언어

냉장고 공장(가상)의 6개 분임조가 매일 생산보고서를 씁니다. 양식은 똑같습니다. 6개 공정 × (계획/생산/양품/불량/불량률/가동/비가동/비고). 그런데 쓰는 말이 전부 다릅니다.

분임조라인언어 특성실제 표현
한마음조A표준에 가까운 정석체캐비닛 프레스, 불량, 비가동
불꽃조B현장 은어 + 일본어 잔재빵꾸, 데나오시, 가타, 시마이 검사, 빠킹
새벽조C영어 혼용NG, Comp' Ass'y, L/S, Down Time
장인조D축약 한자어 행정체냉시조립, 검포, 적요, 특기사항 무
으뜸조E구어체"폼 쏘는 데", "라인 선 시간", "불량난거"
미래조FKPI 약어ACT, Loss율, U/T, D/T, Die C/O

날짜도 2026-07-02 / 26.7.2 / 20260702 세 가지, 합계도 합계 / 토탈 / 계 / TTL 네 가지로 씁니다.

왜 이 문제가 AI에게 딱 맞나: 사람이 취합하면 매일 반복되는 단순 노동이고, 엑셀 함수나 프로그램으로 짜기엔 표현의 변형이 너무 다양합니다. "빵꾸"와 "NG"와 "불량난거"가 같은 뜻임을 아는 것 — 이런 의미 기반 정리가 AI가 가장 잘하는 일입니다.

여러분 업무에도 같은 문제가 있을 겁니다. 팀마다 다른 항목명, 사람마다 다른 표기, 문서마다 다른 형식.

3. 개념 익히기 — 기준을 어디에 둘 것인가

3-1. 프롬프트에 다 적으면 되지 않나요?

물론 됩니다. "빵꾸는 불량으로, 데나오시는 재작업으로…" 를 요청문에 다 적으면 결과는 좋아집니다. 문제는 그 다음입니다.

규칙을 요청문에 적으면

  • 요청문이 A4 두 장이 됩니다. 매번 붙여넣어야 합니다
  • 새 은어가 생기면 그 긴 요청문을 찾아 고쳐야 합니다
  • 어제 쓴 것과 오늘 쓴 것이 같은지 확인할 방법이 없습니다
  • 현장 반장님은 그 요청문을 고칠 수 없습니다

규칙을 파일로 빼면

  • 요청문은 짧아집니다 — "절차"만 남습니다
  • 새 은어는 파일에 한 줄 추가로 끝납니다
  • 파일이 곧 기준입니다. 누가 봐도 같습니다
  • 현장 반장님이 엑셀에서 직접 고칠 수 있습니다

하네스 4원리 중 두 가지
① 역할 분리 — "무엇을(스펙) · 누가(에이전트) · 어떻게(스킬)" 를 한 덩어리로 뭉치지 않습니다.
② 지식의 외부화 — 매핑 규칙·도메인 지식·표준 양식은 프롬프트가 아니라 파일에 둡니다. 지식이 바뀌어도 절차는 그대로입니다.

이렇게 밖으로 뺀 지식 파일을 이 과정에서는 스킬이라고 부릅니다. 이번 실습의 스킬은 엑셀 파일 하나입니다.

좋은 설명서의 3요소 — 내 업무 용어집을 만들 때도 이 세 가지가 들어가야 합니다.

3-3. "모르면 멈춰라" — 가장 중요한 규칙 하나

용어집에 없는 말이 나오면 어떻게 할까요? AI는 기본적으로 그럴듯하게 추측합니다. 그리고 그 추측이 데이터에 섞여 들어가면 나중에 찾아내기 어렵습니다.

그래서 이 실습의 지시서에는 이런 규칙이 들어 있습니다.

지시서에 들어 있는 안전장치
용어집에 없는 표현은 임의로 해석하지 말고
[미확인 용어] 목록으로 별도 보고
🔎

기억할 문장: 자율성이 높은 AI일수록 "모를 때 빠져나갈 출구" 를 만들어 주어야 합니다. 이 출구가 없으면 AI는 반드시 무언가를 지어냅니다. 여러분이 만들 모든 지시서에 이 규칙 한 줄을 넣으세요.

4-2. 결과 검수 — 눈으로 확인할 6가지

AI가 만들었다고 그대로 쓰지 않습니다. 검수도 실습의 일부입니다.

  • 6개 공정명이 모두 표준용어 + 공정코드(P10~P60)로 통일되었는가
  • 은어(빵꾸·데나오시·콤프 등)가 표준용어로 치환되었는가 — 손실 우려 시 (원문: ○○) 병기
  • 숫자가 원본과 100% 같은가 (표현만 바뀌고 수치는 불변)
  • 양품 + 불량 = 생산수량 크로스체크를 했는가
  • 합계·불량률이 엑셀 수식으로 들어갔는가 (값만 박혀 있지 않은가)
  • 치환 이력이 보고되었는가 — 나중에 추적할 수 있어야 합니다
🔎

가장 중요한 항목은 세 번째입니다. AI가 표를 예쁘게 만들면서 숫자를 "정리"해 버리면 그 보고서는 못 씁니다. 그래서 지시서에 "수치는 절대 변경하지 마세요" 가 명시되어 있습니다. 여러분의 지시서에도 바꾸면 안 되는 것을 반드시 적으세요.

공장 데이터(xlsx/)로 2절·4절을 하셨다면, 같은 흐름을 이 광고 데이터로 한 번 더 해볼 수 있습니다. 방법은 ad/README.md 에 있습니다.

① 매번 하는 판단 다섯 가지 — 남에게 설명한 적 없는 것

#내가 매번 하는 판단
1네이버 "노출수", 메타 "노출", 구글 "Impr.", 틱톡 "Impressions" 는 전부 노출 로 통일한다
2메타의 "결과" 컬럼은 캠페인 목적에 따라 의미가 다르다 — 구매 목적일 때만 전환으로 인정한다
3광고비는 매체마다 VAT 포함/별도가 다르다 — 전부 VAT 별도로 환산해 비교한다
4ROAS는 매체 리포트 값을 그대로 쓰지 않고 (전환매출 ÷ VAT별도 광고비) 로 다시 계산한다
5노출 1,000 미만인 소재는 통계로 의미가 없어 "데이터 부족" 으로 표시하고 CTR을 계산하지 않는다
이게 왜 "지식"인가

다섯 개 모두 정하늘 대리 머릿속에만 있던 규칙입니다. 신입이 이 업무를 받으면 2번과 3번에서 반드시 틀립니다. 실제로 지난 분기에 후배가 카카오의 VAT 처리를 놓쳐, 그 매체 ROAS가 310% 대신 282% 로 보고된 적이 있었습니다 — 성과를 실제보다 나쁘게 보고한 셈입니다.

AI도 똑같이 틀립니다. 알려주지 않았으니까요.

③ 파일로 만들기 — 실제로 넣은 프롬프트

정하늘 대리가 Claude Code에 넣은 것
내 업무 용어집을 만들려고 해.

업무: 매주 월요일, 5개 매체(네이버GFA·카카오모먼트·메타·구글애즈·틱톡)
     성과 데이터를 합쳐 광고주 주간 리포트를 만드는 일

용어 매핑:
- 노출수 / 노출 / Impr. / Impressions 는 "노출" 과 같은 뜻
- 소진액 / 광고비 / Cost / Spend 는 "집행액(VAT 별도)" 과 같은 뜻
- 전환 / 구매 / Purchases 는 "전환" 과 같은 뜻
- 단, 메타의 "결과" 컬럼은 캠페인 목적이 구매일 때만 전환으로 인정

형식 규칙:
- 날짜는 YYYY-MM-DD, 금액은 원 단위 정수에 천 단위 콤마
- 비율은 소수점 둘째 자리
- 매체명은 네이버GFA / 카카오모먼트 / 메타 / 구글애즈 / 틱톡 다섯 가지만 사용

금지 사항:
- 원본 수치 변경 금지
- 매체 리포트의 ROAS·CPA를 그대로 쓰지 말고 (전환매출 ÷ VAT별도 집행액)로 재계산
- 노출 1,000 미만 소재는 CTR을 계산하지 말고 "데이터 부족"으로 표시
- 용어집에 없는 컬럼은 추측하지 말고 [미확인] 으로 표시할 것

이 내용을 나의_업무_용어집.md 로 정리해줘.
"언제 쓰는지 / 무엇을 지키는지 / 예시" 세 부분이 들어가게 해줘.

결과: 용어집 한 장이 만들어졌습니다. A4 한 장이 안 됩니다. 그런데 이 한 장이 매주 30분을 줄입니다.

⚠️

이 프롬프트만 그대로 실행하면 결과가 부실합니다. 용어집은 내 데이터를 보면서 쓰는 것이기 때문입니다. 실제 컬럼명을 모르면 AI는 일반적인 문구만 만들어 냅니다.

그래서 정하늘 대리는 파일 5개를 먼저 열어 보고 규칙을 뽑았습니다. 직접 해보려면 ad/ 폴더에서 이렇게 시작하세요 — AI가 실제 컬럼을 읽고 초안을 만들어 줍니다.

Claude Code 입력창에 붙여넣기 (ad 폴더에서)
data 폴더의 매체 파일 5개를 열어서, 컬럼 이름과 값 형식이 매체마다
어떻게 다른지 비교표로 정리해줘. 같은 뜻인데 다르게 적힌 항목,
단위·통화 기준이 다른 항목, 뜻이 애매한 컬럼을 각각 표시해줘.

그 비교표를 보고 내가 판단을 내려 용어집에 적습니다. AI는 차이를 찾아 주고, 규칙을 정하는 것은 사람입니다.

④ 재현성 확인 — 용어집 전후 비교

확인 항목용어집 없이 2회 실행용어집과 함께 2회 실행
항목 이름·순서1회차 "노출/클릭/CTR", 2회차 "노출수/클릭수/클릭률"동일
메타 "결과" 처리1회차 전환으로 인정, 2회차 별도 컬럼구매 목적만 전환 — 동일
VAT 처리둘 다 언급 없음 (그냥 합산)VAT 별도로 환산 후 계산
노출 적은 소재CTR 0.00% 로 표시 (오해 소지)"데이터 부족" 표시
가장 중요한 발견

용어집 없이 돌렸을 때 VAT를 아무도 지적하지 않았습니다. AI도, 결과를 본 사람도. 틀린 줄 모르고 넘어가는 것 — 이것이 AI를 업무에 쓸 때 가장 무서운 지점입니다.

용어집은 "AI를 똑똑하게" 만드는 물건이 아니라 "내가 아는 것을 잊지 않게" 만드는 물건입니다.

7. 스스로 점검

  • 지식 없이 시켰을 때와 있을 때의 차이를 한 문장으로 설명할 수 있다
  • 통합_생산보고서.xlsx 가 생성되었고 검수 6항목을 확인했다
  • 같은 지시를 두 번 돌려 구조가 같은지 비교했다
  • 내 업무 규칙 5개를 뽑아 나의_업무_용어집.md 로 만들었다
  • "모르면 멈춰라" 규칙을 내 용어집에도 넣었다

흔한 실패와 대처

증상왜 생기나대처
엑셀을 못 읽음document-skills 미설치설치가이드 3-8절 재실행 후 Claude Code 재시작
"결과가 원래 같던데요?"실습 A를 한 번만 돌림반드시 /clear 후 두 번 돌려 비교
숫자가 원본과 다름AI가 반올림·정리해 버림지시서의 "수치 불변" 규칙을 강조해 재실행. 이 경우 결과를 폐기
규칙을 긴 문장으로 씀설명하려는 습관"A → B" 표 형태로. 문장이 길수록 AI 해석이 흔들립니다
내 업무 규칙이 안 떠오름너무 익숙해서 의식하지 못함"신입이 이걸 틀리게 했던 적" 을 떠올리면 규칙이 보입니다
