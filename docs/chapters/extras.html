E1. 파이프라인 하네스 — 정책 데이터에서 슬라이드까지

난이도비전공자 가능
모듈slide/
배우는 것수집 → 갱신 → 디자인 생성 → 검수로 이어지는 4단계 파이프라인

공개 정책 데이터를 모아 엑셀 현황판을 갱신하고, 정부 표준 디자인 슬라이드를 자동 생성합니다. 2차시가 단일 프롬프트 ETL이었다면, 여기는 여러 단계가 이어지는 파이프라인형 하네스입니다.

관찰 포인트 — 기준일 셀 하나를 바꾸면 전체가 다시 계산되는 "살아 있는 문서" 구조. 수식으로 계산되는 지표와 하드코딩된 값의 차이를 눈으로 확인하세요.

교안slide/README.md정책 데이터 → 표준 슬라이드 실습

E2. 계약 중심 팬아웃 — 이기종 데이터를 하나로

난이도개발 지식 권장
모듈dashboard/
배우는 것표준 스키마를 먼저 확정해 병렬 개발을 가능하게 하는 구조

설비 200대가 제각각의 형식으로 데이터를 보냅니다 — 숫자 상태코드, 영문 약어, 한글 키, CSV 문자열. 같은 사실이 4가지 형식·3가지 단위·2가지 언어로 도착합니다. 2차시의 "분임조 은어 문제" 가 실시간 스트림으로 확장된 셈입니다.

관찰 포인트 — 5차시에서 배운 계약이 여기서 진가를 발휘합니다. 표준 형식을 먼저 정하면 데이터를 보내는 쪽과 받는 쪽을 동시에 만들 수 있습니다.

난이도개발

배우는 것대화형 진단 → 승인하며 패치 → 교차 리뷰 → 자동 검사
